How should the game be structured?

Three approaches to side-scrolling — each changes how skating, fighting, and frat-burning connect

★ LEVEL 1: SKATE TO THE FRAT ★ ♥♥♥
ΔΨΩ
→ skate right, fight frat bros → reach frat → BOSS FIGHT → burn it 🔥

A — Mario Mode

Each frat is a level. Skate left-to-right, grind rails, fight frat bros along the way. Reach the frat house, beat the boss (frat president), burn it down. 3 levels = rescue. Clean, familiar structure.

Pros

  • Clear progression
  • Easy to pace difficulty
  • Classic feel

Cons

  • Less replayable
  • Finite content

B — Endless Grind

Infinite procedurally-generated street. Frat houses appear randomly. Skate, fight, find a molotov, grind up to the frat roof, torch it. Counter tracks how many you've burned. More roguelike — each run is different.

Pros

  • Highly replayable
  • Familiar to current game
  • Easy to add content

Cons

  • Less structured narrative
  • Harder to pace

C — World Map + Levels

Overworld map (like Mario World) shows 3 frat houses to hit. Pick your target, skate through a unique level to reach it, beat the chapter boss, burn it. Unlocks the rescue sequence after all 3. Most cinematic feel.

Pros

  • Most narrative weight
  • Each frat feels unique
  • Satisfying unlock arc

Cons

  • Most content to build
  • Less replayable
